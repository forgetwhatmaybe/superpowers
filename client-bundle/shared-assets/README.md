# Shared owner adapter assets

Nine reviewed adapter assets for this host family (`codex` and `pi`): per host
`source_checks.py`, `source_interface.py`, `state-schema.json`, `state_io.py`, plus the shared
`version.json`.

Scope: these are closed owner state/adapter interfaces with unobserved captures. They are **not**
a production integration — no production hooks or adapters are registered, no end-to-end
production acceptance is claimed, and captures remain unobserved. Per-machine setup is described
in the repository's deployment documentation.
